Welcome to DevOps Learning

This is a simple webpage for learning DevOps concepts. DevOps combines software development (Dev) and IT operations (Ops) to shorten the systems development life cycle and provide continuous delivery with high software quality.

Key Concepts

  • Continuous Integration (CI)
  • Continuous Delivery (CD)
  • Infrastructure as Code (IaC)
  • Monitoring and Logging
  • Automation
